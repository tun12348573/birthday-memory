# Love Memory Web — Phase 2

## Chạy

```bash
npm install
npm run dev
```

Mở `http://localhost:3000`.

## Mật khẩu demo

`2608`

Đổi trong `components/LockScreen.jsx`.

## Flow hiện tại

1. Màn hình mật khẩu
2. Chuyển cảnh GSAP
3. Lá thư tương tác
4. Nút mở album
5. Album 2 trang + lật trang 3D
6. Nút trang trước/sau + progress dots
